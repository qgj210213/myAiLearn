# 周2：机器学习入门（监督学习、评估指标）

重点学习：训练/测试/验证流程、损失函数、常见模型（线性回归、树模型）、评估指标（精确度、召回率、F1、AUC）。

必学要点：
- 先建立机器学习最基础的训练思维：知道数据怎么切分、模型怎么训练、结果怎么评估。
- 理解常见监督学习任务的判断方式：分类和回归分别看什么指标，为什么不能只看准确率。
- 会用 sklearn 跑通一个完整的小实验：读数据、训练模型、评估结果、保存模型。

必做小项目（3–7 天）：
- 无必做项目（专注机器学习基础练习）

工作要点：
- 能解释模型选择与评价指标
- 熟悉 sklearn 基本 API
- 能讲清项目中数据划分与验证策略

## 周2 详细要学习内容（表格）

| 主题 | 详细要学习的内容 | 必须掌握 | 进阶 / 备注 |
|---|---|---:|---|
| 机器学习基础概念 | 监督学习、分类/回归、特征与标签、训练集/验证集/测试集 | 能清楚说出一个 ML 项目的基本流程 | 无监督学习可放后面再学 |
| 数据预处理 | 缺失值处理、类别编码、标准化/归一化、特征选择基础 | 能对结构化数据做基础清洗并送入模型 | 特征工程方法可后续补充 |
| 常见模型 | 线性回归、逻辑回归、决策树、随机森林、XGBoost 基本认知 | 知道不同模型适合什么场景 | Boosting 细节属于进阶 |
| 模型评估 | Accuracy、Precision、Recall、F1、AUC、MSE、MAE | 能按任务选择正确指标并解释原因 | PR 曲线、ROC 曲线可作为补充 |
| 训练与验证 | 过拟合、欠拟合、交叉验证、超参数调优基础 | 能识别模型效果不好的常见原因 | 网格搜索/贝叶斯优化可进阶 |
| sklearn 实践 | fit、predict、score、pipeline、model save/load | 能独立写一个 sklearn 训练脚本 | pipeline 组合优化可后续掌握 |
| 结果解释 | 混淆矩阵、特征重要性、误差分析 | 能看懂模型错在哪里 | SHAP/LIME 可放到进阶 |

## 每日/每项练习建议
- Day 1：熟悉训练集、验证集、测试集的区别，手写一个完整训练流程笔记。
- Day 2：用 sklearn 跑一个分类任务，输出准确率、召回率、F1。
- Day 3：换一个模型重新训练，对比不同模型效果和训练时间。
- Day 4：练习混淆矩阵和误差分析，找出模型容易错的样本。
- Day 5：把训练、预测、模型保存整理成一个可复现脚本。
