# 必做小项目、面试要点、速学资源与小贴士（统一文件）

## 必做小项目（每个 3–7 天）

- RAG 问答系统（文档→向量库→API）
  - 关联学习周：Week4, Week5, Week6, Week8
  - 流程：文档清洗 → embedding → 向量库索引 → 检索 + LLM 生成
  - 目标：实现简单 QA API，能根据文档返回准确上下文并生成答案

- 多步骤 Agent（检索→决策→执行工具）
  - 关联学习周：Week4, Week5, Week7, Week8
  - 流程：输入解析 → planner（决策步骤）→ 调用工具（检索/API/执行）→ 汇总结果
  - 目标：实现一个可重复的多步任务（如：从文档找信息并执行小脚本），并记录每步日志

- 部署演示（Docker + 简单监控 + README）
  - 关联学习周：Week1, Week6, Week8
  - 内容：把其中一个项目容器化，提供 API、简单健康检查、日志与一个基础监控指标
  - 目标：能在本地或云上运行并用 README 演示如何发起请求和读取状态

---

## 工作要点

- 能解释模型选择、评价指标与工程权衡（延迟/成本/精度）
- 熟悉常用库并能现场写推理/接口代码：PyTorch、Hugging Face、LangChain、FAISS
- 能讲清项目架构、数据流与故障排查流程（日志、回退、监控）

## 速学资源（选一）

- Hugging Face 快速教程与示例 repo
- DeepLearning.AI 的短期课程或微课
- 官方文档与社区示例（LangChain、FAISS、各向量库）

## 小贴士

- 项目要能 demo（视频或 README + POST 请求）
- 把代码放到 GitHub，写清可复现步骤与依赖
- 优先做可复现的小体量系统，再逐步扩展规模与优化
