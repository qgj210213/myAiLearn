## 1. 基础语法

### 1.1 变量

| 要点 | 说明 |
|------|------|
| 类型模型 | 动态类型：名字绑定到对象，无需声明类型 |
| 命名习惯 | 变量/函数用 `snake_case`；常量常用全大写（约定） |
| 赋值语义 | 赋值是绑定引用；多个变量可指向同一对象 |

| 示例 | 含义 |
|------|------|
| `count = 0` | 整数绑定到 `count` |
| `user_name = "Ada"` | 字符串绑定 |
| `PI = 3.14159` | 浮点绑定（作常量名是习惯） |

### 1.2 内置数据类型

| 类型 | 说明 | 示例 |
|------|------|------|
| `int` | 整数 | `42`, `-1` |
| `float` | 浮点 | `3.14` |
| `bool` | 布尔 | `True`, `False` |
| `str` | 不可变文本 | `"hello"` |
| `list` | 有序可变序列 | `[1, 2, 3]` |
| `tuple` | 有序不可变序列 | `(1, 2)` |
| `dict` | 键值映射 | `{"a": 1}` |
| `set` | 无序、元素不重复 | `{1, 2, 3}` |
| `NoneType` | 空值 | `None` |

| 用途 | 写法 |
|------|------|
| 查看类型 | `type(x)` |
| 类型判断 | `isinstance(x, int)` |

### 1.3 运算符

| 类别 | 运算符 | 说明 |
|------|----------|------|
| 算术 | `+` `-` `*` `/` | `/` 为真除（结果多为 `float`） |
| 算术 | `//` `%` `**` | 整除、取余、幂 |
| 比较 | `==` `!=` `<` `>` `<=` `>=` | 值相等/大小比较 |
| 逻辑 | `and` `or` `not` | 短路求值 |
| 成员 | `in` `not in` | 成员关系 |
| 身份 | `is` `is not` | 是否同一对象（勿与 `==` 混用） |
| 位运算 | `&` `^` `~` `<<` `>>` 与按位或（键盘竖线键） | 业务脚本中较少用 |

## 2. 控制结构

### 2.1 分支 `if`

| 形式 | 语法要点 |
|------|----------|
| 多分支 | `if` → `elif`（可多个）→ `else`（可选） |
| 三元表达式 | `结果A if 条件 else 结果B` |

| 结构 | 代码骨架 |
|------|----------|
| 分级判断 | `if score >= 90: ... elif score >= 80: ... else: ...` |

### 2.2 循环 `for`

| 要点 | 说明 |
|------|------|
| 作用 | 遍历**可迭代对象**（`list`、`str`、`range`、`dict` 的键/值等） |
| 中断 | `break` 跳出循环；`continue` 跳过本轮剩余语句 |
| `for ... else` | 循环正常结束（未 `break`）时执行 `else` 块（了解即可） |

| 写法 | 示例（单行） |
|------|----------------|
| 计数遍历 | `for i in range(5):` → `i` 为 `0..4` |
| 字符遍历 | `for ch in "abc":` |
| 字典键值 | `for k, v in items.items():` |

### 2.3 循环 `while`

| 要点 | 说明 |
|------|------|
| 语义 | 条件为真则重复执行循环体 |
| 注意 | 需保证条件最终会变为假，避免死循环 |

| 骨架 | 含义 |
|------|------|
| `while n > 0: ... n -= 1` | 条件驱动递减 |

## 3. 函数

### 3.1 定义与返回值

| 要点 | 说明 |
|------|------|
| 定义 | `def name(参数):` + 缩进块 |
| 返回值 | `return 表达式`；无 `return` 或裸 `return` → 实际返回 `None` |

| 最小示例 | 作用 |
|----------|------|
| `def add(a, b): return a + b` | 两参数求和并返回 |

### 3.2 参数形式

| 形式 | 语法/示例 | 说明 |
|------|-----------|------|
| 位置参数 | `def f(a, b):` | 按顺序传入 |
| 默认参数 | `def f(a, b=0):` | `b` 可省略；默认值在**定义时**求值一次 |
| 可变默认 | 慎用 `def f(x=[]):` | 共享同一列表对象；常用 `None` 进函数再新建 |
| 仅限关键字 | `def f(a, *, b):` | `b` 必须 `b=...` 传入 |
| 可变位置 | `*args` | 多余位置参数收集为 `tuple` |
| 可变关键字 | `**kwargs` | 多余关键字参数收集为 `dict` |

| 组合示例 | 含义 |
|----------|------|
| `def demo(a, *args, b=1, **kwargs):` | 位置 + 星元组 + 默认关键字 + 星字典 |

### 3.3 作用域 LEGB

| 层级 | 字母 | 含义 |
|------|------|------|
| L | Local | 当前函数内名字 |
| E | Enclosing | 外层嵌套函数（闭包） |
| G | Global | 模块顶层 |
| B | Built-in | 内置命名空间 |

| 场景 | 关键字 | 说明 |
|------|----------|------|
| 在函数内给**模块级**变量赋值 | `global x` | 否则 `x = ...` 会新建局部变量 |
| 在嵌套函数内给**外层函数**的局部变量赋值 | `nonlocal x` | Python 3 |

| 只读全局 | 赋值到全局 |
|----------|------------|
| 可直接读全局名 | 必须 `global` 后再赋值 |

## 4. 模块与包

### 4.1 `import` 写法

| 写法 | 示例 |
|------|------|
| 导入整个模块 | `import os` |
| 从模块导入对象 | `from datetime import datetime` |
| 别名 | `import json as js` |
| 子模块/符号 | `from pathlib import Path` |

### 4.2 模块 vs 包

| 概念 | 说明 |
|------|------|
| 模块 | 单个 `.py` 文件；首次 `import` 会执行其顶层代码（一般只做定义） |
| 包 | 含 `__init__.py` 的目录（Python 3.3+ 命名空间包可没有该文件，显式包仍常见） |
| `__init__.py` | 标记目录为包；可集中导出 API、包级初始化；可为空 |

### 4.3 搜索与命名

| 要点 | 说明 |
|------|------|
| 搜索顺序 | 依 `sys.path`：脚本目录、标准库、`site-packages` 等 |
| 命名冲突 | 勿将自写模块命名为 `json.py`、`os.py` 等与标准库同名 |

## 5. 内置库速查

### 5.1 `os`

| 类别 | 常用 API | 用途 |
|------|----------|------|
| 进程环境 | `os.environ` | 环境变量字典 |
| 工作目录 | `os.getcwd()` `os.chdir(path)` | 查询/切换当前目录 |
| 路径/文件 | `os.path.exists` `os.listdir` `os.mkdir` 等 | 文件系统操作 |
| 备注 | 路径拼接现代风格可用 `pathlib.Path` | 与 `os.path` 勿混用无文档约束 |

| 示例（单行） | 作用 |
|--------------|------|
| `os.environ.get("HOME")` 或 `USERPROFILE` | 跨平台取用户主目录环境变量 |

### 5.2 `sys`

| API | 用途 |
|-----|------|
| `sys.argv` | 命令行参数列表；`argv[0]` 为脚本名 |
| `sys.path` | 模块搜索路径（列表，可运行时查看） |
| `sys.exit(code)` | 退出进程；`0` 通常表示成功 |

| 典型用法 | 代码骨架 |
|----------|----------|
| 参数个数检查 | `if len(sys.argv) < 2: print(...); sys.exit(1)` |

### 5.3 `datetime`

| 对象/模块 | 说明 |
|-----------|------|
| `datetime.date` | 日期（年月日） |
| `datetime.time` | 时间（时分秒等） |
| `datetime.datetime` | 日期+时间（注意与**模块名**同名，导入易混） |
| `datetime.timedelta` | 时间差，可与 `datetime` 加减 |
| `datetime.timezone` | 时区信息（如 `timezone.utc`） |

| 常见操作 | 示例 |
|----------|------|
| 当前本地时间 | `datetime.now()` |
| 当前 UTC | `datetime.now(timezone.utc)` |
| ISO 字符串 | `dt.isoformat()` |
| 格式化输出 | `dt.strftime("%Y-%m-%d %H:%M:%S")` |
| 解析字符串 | `datetime.strptime(s, fmt)` |

### 5.4 `json`

| JSON | Python |
|------|--------|
| object | `dict` |
| array | `list` |
| string | `str` |
| number | `int` / `float` |
| `true` / `false` / `null` | `True` / `False` / `None` |

| 函数 | 作用 |
|------|------|
| `json.dumps(obj)` | Python 对象 → JSON **字符串** |
| `json.loads(text)` | JSON 字符串 → Python 对象 |
| `json.dump(obj, fp)` | 写入类文件对象 |
| `json.load(fp)` | 从类文件对象读取 |

| 建议 | 说明 |
|------|------|
| 中文与可读性 | `dumps`/`dump` 使用 `ensure_ascii=False`，可选 `indent=2` |
| 文件编码 | `open(..., encoding="utf-8")`，减少 Windows 默认编码问题 |
